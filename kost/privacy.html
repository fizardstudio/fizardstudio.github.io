Kebijakan Privasi

Aplikasi: Aplikasi Manajemen Kost · Pengembang: Mochamad Firman (Fizard Studio), Bandung · Berlaku sejak 26 Oktober 2026

1. Ringkasan

Aplikasi Manajemen Kost adalah aplikasi yang dipasang dan dijalankan di komputer pengelola kost sendiri. Seluruh data kamar, penghuni, tagihan sewa, pembayaran, kas, meteran, booking, dan keluhan disimpan di komputer tersebut (folder data di samping aplikasi). Pengembang tidak mengoperasikan server untuk aplikasi ini dan tidak menerima, menyimpan, atau melihat data pengguna. Data tersebut milik pengelola kost yang memakai aplikasi.

2. Data yang diproses aplikasi

  • Data yang diketik atau diimpor pengguna ke dalam aplikasi, termasuk nama dan nomor WhatsApp, tersimpan hanya di komputer pengguna.
  • Saat pengguna menekan tombol kirim WhatsApp, aplikasi membuka WhatsApp di perangkat pengguna dengan pesan yang sudah terisi. Pesan dikirim oleh pengguna sendiri melalui WhatsApp; pengembang tidak menerima salinannya.
  • Kode lisensi diperiksa di dalam aplikasi tanpa mengirim data ke pengembang.

3. Cadangan ke Google Drive (opsional)

Fitur cadangan Google Drive hanya aktif bila pengguna menekan “Hubungkan Google Drive” di aplikasi dan memberikan izin. Aplikasi meminta izin berikut:

  • https://www.googleapis.com/auth/drive.file — membuat folder “Cadangan Aplikasi Manajemen Kost” serta membuat, memperbarui, membaca, dan menghapus file cadangan yang dibuat oleh aplikasi ini sendiri. Aplikasi tidak dapat melihat atau mengubah file lain di Google Drive pengguna.
  • openid dan email — hanya untuk menampilkan alamat email akun yang terhubung di dalam aplikasi.

Cara data Google digunakan:

  • File cadangan (berisi data aplikasi milik pengguna) dikirim langsung dari komputer pengguna ke Google Drive milik pengguna, dan hanya diunduh kembali saat pengguna memulihkan data.
  • Token akses Google disimpan hanya di komputer pengguna dan tidak disertakan di dalam file cadangan.
  • Data tidak dijual, tidak dibagikan kepada pihak ketiga, dan tidak dipakai untuk iklan atau melatih model AI.

Penggunaan informasi yang diterima dari Google API mematuhi Google API Services User Data Policy, termasuk persyaratan Limited Use.

4. Menghapus akses dan data

  • Di aplikasi: Pengaturan → Cadangan Google Drive → Putuskan. Token dihapus dari komputer dan akses dicabut.
  • Di akun Google: myaccount.google.com/permissions → pilih Aplikasi Manajemen Kost → hapus akses.
  • File cadangan dapat dihapus kapan saja dari folder “Cadangan Aplikasi Manajemen Kost” di Google Drive.
  • Data di komputer dihapus dengan menghapus folder data aplikasi.

Privacy Policy (English)

Aplikasi Manajemen Kost (Boarding House Management App) is a desktop application installed and run on the user's own computer. All room, tenant, rent billing, payment and bookkeeping records are stored locally in the app's data folder. The developer (Mochamad Firman, Fizard Studio) operates no server for this app and never receives user data. WhatsApp messages are sent by the user from their own WhatsApp; license codes are verified offline.

The optional Google Drive backup requests drive.file (create, read and manage only the backup folder “Cadangan Aplikasi Manajemen Kost” and files created by this app), plus openid and email (to display the connected account). Backups are uploaded directly from the user's computer to the user's own Google Drive and are downloaded only when the user restores. OAuth tokens stay on the user's computer and are excluded from backups. Data is not sold, shared with third parties, used for advertising, or used to train AI models. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Users can disconnect in the app (Settings → Google Drive backup → Disconnect) or revoke access at myaccount.google.com/permissions. Contact: firmanmochamad09@gmail.com
