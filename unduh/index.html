Cara mencoba

  1. Ekstrak zip
    Klik kanan file zip, pilih Extract All. Jangan dijalankan dari dalam zip.
  2. Lihat data contoh
    Klik dua kali Jalankan-DEMO.bat. Browser terbuka berisi data contoh. Masuk dengan admin / rahasia1.
  3. Pakai untuk data sendiri
    Klik dua kali file .exe, isi nama sekolah / kost dan buat akun admin. Masa coba 3 hari dimulai.

Bila Windows menampilkan “Windows protected your PC”, klik More info lalu Run anyway. Bila Firewall bertanya, izinkan Private networks supaya bisa dibuka dari HP.

Pertanyaan

Setelah 3 hari bagaimana?

Data tetap aman dan bisa dilihat atau dicetak, tetapi tidak bisa menambah data. Hubungi kami, setelah pembayaran Anda menerima kode lisensi yang tinggal ditempel di menu Pengaturan. Data yang sudah diisi tetap terpakai.

Apakah data saya dikirim ke internet?

Tidak. Semua data disimpan di komputer Anda sendiri. Cadangan ke Google Drive hanya aktif bila Anda membeli dan menyalakan modul Cadangan Google Drive, dan tersimpan di Drive milik Anda.

Butuh bantuan memasang atau ingin demo langsung?

Hubungi kami lewat WhatsApp. Demo lewat video call atau datang langsung (area Bandung), gratis.

Sudah mencoba dan cocok?

Kirim pesan untuk kode lisensi atau pertanyaan harga.
